# Language Policy

All written content in this project must be in **English**. This includes:

- Code comments (inline and block)
- Documentation (README, guides, etc.)
- GitHub Issues (title and body)
- Pull Requests (title and body)
- Commit messages
- Changeset descriptions

## Exception

Conversations with the user (e.g., Claude Code chat) are **exempt** from the English-only rule. Respond in whatever language the user uses. This exception applies only to interactive dialogue, not to any project artifacts produced during the conversation.
