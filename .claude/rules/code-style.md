# Code Style

## TypeScript / JavaScript

- Formatter: **Prettier**, Linter: **oxlint**
- No semicolons
- Single quotes
- Print width: 120
- Tab width: 2
- Trailing commas: all
- Arrow function parentheses: always

## Rust

- Formatter: **rustfmt** (`cargo fmt`)
- Follow standard Rust conventions as enforced by `rustfmt.toml`

## General

- Unused variables should be prefixed with `_`
- Unused imports are not allowed
